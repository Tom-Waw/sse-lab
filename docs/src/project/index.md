# Project Management

This section documents the software project management artifacts.

The goal is not to create heavyweight process documentation. The goal is to make the project’s purpose, scope, assumptions, risks, and delivery approach explicit enough that engineering decisions can be understood in context.

`sse-lab` uses hospitality operations as a realistic domain for practicing and demonstrating end-to-end software systems engineering.

## Current Artifacts

- [Project Vision](vision.md)
- [Scope](scope.md)
- [Stakeholder Analysis](stakeholder-analysis.md)
- [Requirements Engineering](requirements-engineering.md)
- [Interviews](interviews/index.md)

## Planned Artifacts

Future project-management artifacts may include:

- generalized interview notes;
- roadmap and milestones;
- risk and assumptions log;
- quality plan.

These artifacts should remain practical. They should guide implementation, architecture decisions, experiments, and documentation.
