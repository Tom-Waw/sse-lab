# Software Systems Engineering Lab

Designing, testing, measuring, and evolving production-inspired distributed systems.

## Purpose

`sse-lab` is a personal software systems engineering monorepo. It acts as both a portfolio project and a learning lab for backend engineering, distributed systems, architecture, infrastructure, performance engineering, and observability.

The goal is to design and evolve a realistic system through measurable engineering experiments, not to build a toy application.

## Engineering Philosophy

`sse-lab` is built around architectural evolution: start simple, measure real limitations, improve the design deliberately, and document the trade-offs.
